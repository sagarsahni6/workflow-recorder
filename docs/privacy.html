Privacy-First Architecture

Privacy Policy

Workflow Recorder Chrome Extension • Effective Date: September 2026 • Version 1.0.0
Key Commitment: Workflow Recorder does not collect, transmit, monetize, or share any personal user data. All recorded actions, selectors, and exported workflows are processed and stored 100% locally in your browser.

1. Data Collection & Processing

Workflow Recorder is designed with strict Privacy-by-Default principles:

  • Zero External Telemetry: The extension does not use any analytics services (e.g. Google Analytics, Mixpanel, Sentry) and makes zero external HTTP/HTTPS network requests.
  • Local Storage Only: All workflows, steps, and optional screenshots are saved exclusively inside your browser's local IndexedDB database and chrome.storage.local.
  • No Account Required: You do not need to register, log in, or provide an email address to use this extension.

2. Automatic PII & Password Masking

To protect your confidential information while recording automation workflows, Workflow Recorder incorporates a built-in privacy filter:

  • Password Elements: Input fields with type="password" are automatically detected. Real keystrokes are never recorded in plaintext and are substituted with masked tokens (e.g., {{password}}).
  • Sensitive Field Detection: Inputs with attributes or labels matching sensitive patterns (such as credit card numbers, CVVs, Social Security numbers, banking pins, or OTPs) are flagged and automatically masked.
  • URL Sanitization: Authentication tokens, session IDs, and secret keys embedded in query parameters are scrubbed before storage.

3. Chrome Permissions & Justifications

The extension requests only the minimum permissions required to perform browser automation recording:

Permission Usage Rationale
storage Used to store user preferences, recording configurations, and workflow step data locally in your browser.
tabs Used to identify the active tab when you click Record and detect tab navigation/URL changes during workflow recording.
scripting Used to dynamically inject the recorder listener into web pages when recording is actively triggered by the user.
downloads Used exclusively to allow you to save and download exported automation test files (Playwright, Puppeteer, Selenium, Cypress, JSON) to your local disk.
activeTab Used to interact with and capture visual screenshots of the active browser tab when requested.
<all_urls> Required so users can record test automation workflows on any web application or site of their choice.

4. Third-Party Sharing & Disclosure

We do not sell, rent, license, or transmit user information to any third parties. We do not use user data for targeted advertising, credit scoring, or promotional activities.

5. Data Retention & Deletion

Because all data is stored locally on your device, you maintain complete control over your data at all times. You can delete individual workflows directly from the Workflow Editor or clear all extension data at any time via Chrome's extension management settings (chrome://extensions).

6. Changes to this Policy

If we make any changes to this Privacy Policy, the updated document will be published with an updated version number and effective date.

7. Contact & Open Source

If you have questions about this privacy policy or wish to inspect the open source implementation, please visit our project repository or contact the extension maintainer.
